This Week 3 project focuses on Monitoring, Logging, and Cloud Security Setup Simulation as part of cloud engineering practice. The project demonstrates how an application environment can be observed, analyzed, and secured using a structured and repeatable workflow without requiring a live AWS account. The implementation contains an application simulator, a monitoring engine, a log analyzer, and a cloud security audit module.

The application simulator generates structured JSON logs containing timestamps, service information, log levels, request identifiers, HTTP status codes, and response latency. This provides realistic application activity that can be analyzed automatically. The monitoring engine simulates important operational metrics such as CPU utilization, memory utilization, disk usage, request latency, and error rate. Each metric is compared with configurable thresholds, and alerts are generated whenever a value exceeds the defined limit.

The log analyzer processes the generated application logs and provides useful operational information such as total events, error counts, status-code distribution, and average latency. In addition, the security audit module checks important cloud security practices including private database access, restricted administrative access, encryption at rest and in transit, least-privilege IAM, privileged-user MFA, logging, and blocking of unused network ports.

The project is organized into separate source, configuration, documentation, and script directories, making it modular and easy to understand. Testing can be performed locally using Python and PowerShell without installing third-party packages or configuring AWS credentials. Overall, this project demonstrates practical understanding of cloud observability, logging, alerting, security controls, and repeatable infrastructure operations. It provides a foundation that could later be connected to real AWS services such as CloudWatch, CloudTrail, AWS Config, and other security and monitoring services.
